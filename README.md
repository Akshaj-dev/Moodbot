# MOODBOT 
### Your Personal AI Voice Companion

MOODBOT is an interactive web-based companion designed to make technology feel more personal, engaging and enjoyable. Its main feature is S.A.M. (Synthetic Autonomous Machine), a virtual companion that allows users to interact through voice and text.

## About the Project

MOODBOT combines an interactive visual interface with a conversational companion. S.A.M. is designed to have a playful, witty, supportive and approachable personality, making interactions feel more natural and less robotic.

The project focuses on combining web development, interactive design and voice technology to create a more engaging user experience.

## How It Works

MOODBOT is built using three main web technologies:

- **HTML:** Creates the structure and layout of the website, including the S.A.M. Voice Companion section.
- **CSS:** Controls the visual appearance, colours, animations, layout and overall design.
- **JavaScript:** Powers the interactive features, expressions, blinking animations, voice recognition, text input and conversational responses.

The project also uses browser-based speech technologies:

- **Speech Recognition:** Allows users to communicate with S.A.M. using their microphone.
- **Speech Synthesis:** Allows S.A.M. to speak responses aloud.
- **Text Input:** Provides an alternative way to communicate with S.A.M.

Users can activate voice mode using the Enable Voice button and use the wake phrase "Hey S.A.M." to interact with the companion. Alternatively, they can choose to ask questions by typing.

## Meet S.A.M.

S.A.M. stands for **Synthetic Autonomous Machine**.

S.A.M. is the virtual companion at the centre of MOODBOT. The aim is to give it a recognisable personality rather than making it feel like a basic chatbot.

Its intended personality includes:

- Playful and witty conversations.
- A modern and natural communication style.
- Supportive and encouraging responses.
- Light humour and personality.
- Voice-based interaction.

The current version includes the voice companion interface, voice controls and text interaction features.

## Why I Made It

I created MOODBOT because I wanted to explore how artificial intelligence and interactive design could be combined to create a more engaging digital companion.

Rather than creating another traditional chatbot, I wanted to experiment with voice interaction, animations, expressions and personality to make the experience feel more interactive.

Through this project, I have developed my understanding of HTML, CSS, JavaScript, browser speech technologies and the process of building and deploying a web application.

## How to Run MOODBOT

1. Clone or download this GitHub repository.
2. Open the project folder.
3. Open `index.html` in a supported web browser.
4. Allow microphone permissions when using voice interaction.
5. Use the Enable Voice button or Ask by Typing option to interact with S.A.M.

**Note:** Voice recognition availability depends on browser support and permissions.

## Hardware and Firmware

MOODBOT is currently a software-based web application. It does not use a dedicated microcontroller, physical electronic circuit or hardware board.

Therefore, embedded firmware and an electronics schematic are not applicable to the current version of this project.
